## 1. 标志构成与几何

### 1.1 构成

标志 = **图形 + 字标** 两个元素。图形是四枚同形的楔形块，绕中心 90° 各转一次，朝中心收拢；
字标是 **astraroad**（全小写）的 Poppins SemiBold 转曲轮廓。两元素之间只有「间距」这一种关系，
不得叠加、变形、加特效。

### 1.2 图形几何（以 96×96 单位画布为准，锁定值）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | `viewBox 0 0 96 96` | 16px 时 1px = 6 单位；32px 时 1px = 3 单位 |
| 墨迹外接框 | 92 × 92（x/y = 2…94） | 四周内边距 2 单位 = 画布的 2.08% |
| 楔形块 | 4 枚，同一基本形旋转 0/90/180/270° | 不是四次手画，四处误差为零 |
| **尖角夹角** | **60.8°** | 两条主斜边（斜率 31.08 : 18.24）之间的锐角；四条斜边两两平行 |
| 中心留白 | **26 单位**（半对角 13） | 占画布的 27.1%、占墨迹高 92 的 28.3%；四条通道的收束点 |
| 通道外口 `w_out` | 26 单位 | 在外切角处的宽度 |
| 通道内口 `w_in` | 6.5 单位 | 在中心端处的宽度 → 外∶内 = **4∶1**，通道向中心收窄 |
| 外切角 `cham` | 26 单位 | 45° 切角，画布四角被切掉 |
| 圆角 | 外角 **R4.5** / 内角 **R1.6** / 口部 **R0.8** | 平涂单色，无渐变、无描边、无 `<text>` |

> 中心留白与四条通道是这枚标志唯一的识别点：**任何尺寸下都必须看得见中心还空着**（判据见 §3.2）。

### 1.3 四色方位（固定，不得对调）

| 方位 | 语义 | 色 | HEX |
|---|---|---|---|
| 上 N | 资本 | 资本蓝 | `#4C76CB` |
| 右 E | 货物 | 货物橙 | `#C05C17` |
| 下 S | 服务 | 服务紫 | `#A958BE` |
| 左 W | 信息 | 信息绿 | `#2C8A34` |

### 1.4 字标

| 项 | 值 |
|---|---|
| 字体 | **Poppins SemiBold**（转曲为路径，文件内不含 `<text>`，不依赖本机装字体） |
| 字距 | **+0.02em**（在 Poppins 原始侧边距上统一加 0.02em；`astraroad` 的小写圆字若不加会粘连） |
| 大小写 | 全小写 `astraroad` |
| 禁忌 | **不得使用 Xenon BC 等 design.com 自研字体**（All rights reserved，不可外用）；本机 `XenonBold.ttf` 只是同名无关衬线体，同样不用 |

## 2. 三种锁定与色彩变体

| 锁定 | 构成 | 画布比例 | SVG 文件 |
|---|---|---|---|
| **图标 Icon** | 仅图形，正方形 | 1 : 1（96 × 96） | `astraroad-icon.svg` |
| **横向 Horizontal** | 图形在左、字标在右，字标 x 高与图标中心线对齐 | **4.113 : 1**（394.81 × 96） | `astraroad-horizontal.svg` |
| **竖向 Vertical** | 图形在上居中、字标在下居中 | **1.410 : 1**（211.2 × 149.76） | `astraroad-vertical.svg` |

比例构成（锁定值，改动即算新版）：

- 横向：字标 x 高 = 图标高的 **0.31**；图标与字标净距 = 图标高的 **0.21**
- 竖向：字标墨迹宽 = 图标宽的 **2.20**；图标下缘到字标上缘净距 = 图标高的 **0.24**

### 2.1 色彩变体（四种用法 × 三种锁定）

| 后缀 | 名称 | 组成 | 用在哪 |
|---|---|---|---|
| （无） | 彩色主版 | 四色图形 + `#161718` 字标 | 所有浅底：白、浅灰、浅色照片（底亮度 L > 0.5） |
| `-on-dark` | **反白版（深底）** | 四色图形 + **白色**字标 | 深底：`#0A1A1A`、深色照片、深色 PPT 母版 |
| `-mono` | 单色黑 | 全 `#161718` | 单色印刷、传真、蚀刻/打标、低精度丝印、盖章件 |
| `-mono-white` | 单色白 | 全 `#FFFFFF` | 深色**照片/复杂纹理**底、单色反白印刷 |

图标只有三档（`-mono`、`-white` 与彩色）；图标本身没有「深底版」，因为四色图形在深底上不需要改色（§5.2 实测）。

> **为什么「反白版」保留四色图形**：业主口径中的「反白（深底）」在本体系中拆成两支——
> `-on-dark`（图形保四色、字标反白）与 `-mono-white`（全白）。
> 依据是实测：四色图形在 `#0A1A1A` 上的对比度 **4.05–4.11 : 1**，全部过线（§5.2）；
> 此时若整枚标志转白，会白丢品牌色。只有在**底色不可控**（照片、纹理、渐变）时才降到全白。

## 3. 最小尺寸

| 锁定 | 最小尺寸 | 折算 | 实测备注 |
|---|---|---|---|
| 图标 · 微缩形 | **宽 ≥ 16px** | — | 16px 档**必须**用 `icon-micro16`（中心孔 3px） |
| 图标 · 标准形 | **宽 ≥ 20px** | — | 18px 时中心孔塌到 1px，判「糊」；20px 起 3px |
| 横向锁定 | **宽 ≥ 96px** | 图标高 23.3px、字标 x 高 7.2px | 96px 是"还能读"的下限；**≤ 110px 建议直接用图标**（x 高 < 8px 时 8 个字母挤在一起） |
| 竖向锁定 | **宽 ≥ 64px** | 图标 29.1px、字标 x 高 6.9px | 64px 是业主定的硬底线；**实操下限 110px**（x 高 11px、总高 78px）。低于 110px 一律改用图标锁定 |

换算公式（便于现场量）：
`横向字标 x 高 = 0.0754 × 总宽`；`竖向字标 x 高 = 0.1076 × 总宽`；`竖向总高 = 0.709 × 总宽`。

### 3.2 小尺寸可辨判据（量测口径）

- 墨块（4 邻接连通域）必须 **= 4**；降到 1 就是四枚块黏成一团
- 中心孔（从图心向上下左右连续背景像素的最小宽度）**≥ 2px** 判可辨；**≤ 1px 判糊**
- 复现：`python3 设计部/工具/logo_measure.py <png>`

## 4. 留白（Clear Space）

**最小留白 x = 图标高 ÷ 4。** 横向锁定（图标高 96）= 24 单位；任何情况下标志四边到
文字、图形、色块、裁切边的距离都不得小于 x。

- 该留白**含**图标自身的 2 单位内边距，即从**墨迹外接框**起量
- 竖向锁定同样按"图标高"取 x（图标高 = 锁定总宽 ÷ 2.20）
- 站点头部的实现值：`.logo-area { gap: 16px }`，在标志高 60px 时 x = 15px，16px ≥ 15px 合规

示意图：`clear-space.svg`（浅绿框 = 留白边界，灰虚线 = 墨迹边界）

> 留白内**不得**出现：文字（含口号 tagline）、分隔竖线、其他 logo、按钮、页面裁切边。

## 5. 色值

### 5.1 色表

| 名称 | HEX | RGB | 用途 |
|---|---|---|---|
| 资本蓝 | `#4C76CB` | 76, 118, 203 | 上向 |
| 货物橙 | `#C05C17` | 192, 92, 23 | 右向 |
| 服务紫 | `#A958BE` | 169, 88, 190 | 下向 |
| 信息绿 | `#2C8A34` | 44, 138, 52 | 左向 |
| 字标墨色 | `#161718` | 22, 23, 24 | 浅底字标 |
| 站点底色 | `#0A1A1A` | 10, 26, 26 | 深底基准（astraroad.com 页面底色） |
| 强调绿（沿用） | `#00D084` | 0, 208, 132 | 站点既有强调色，**不属于标志**，不得用于标志内部 |

### 5.2 对比度实测（WCAG 2.x 亮度对比 ＋ CIEDE2000）

| 色 | on `#0A1A1A` | ΔE00 | on `#FFFFFF` | ΔE00 | 判定 |
|---|---|---|---|---|---|
| `#4C76CB` 蓝 | **4.05 : 1** | 39.8 | **4.41 : 1** | 43.2 | 过（≥3:1 图形判据） |
| `#C05C17` 橙 | **4.07 : 1** | 46.3 | **4.39 : 1** | 44.7 | 过 |
| `#A958BE` 紫 | **4.11 : 1** | 38.3 | **4.35 : 1** | 44.4 | 过 |
| `#2C8A34` 绿 | **4.08 : 1** | 40.9 | **4.38 : 1** | 44.2 | 过 |
| 字标 `#161718` on 白 | — | — | **17.95 : 1** | 89.0 | 过 |
| 字标白 on `#0A1A1A` | **17.86 : 1** | 88.9 | — | — | 过 |

**结论：四色图形在 `#0A1A1A` 与白底上都 ≥ 4.0 : 1，全部过 3 : 1 图形判据，深底不需要改色。**
复现：`python3 设计部/工具/contrast.py cr <前景> <背景>`

### 5.3 用色规则

1. **深底（底亮度 L ≤ 0.18）**：图形保四色，字标转白（`-on-dark`）。
2. **浅底（L > 0.18）**：图形保四色，字标 `#161718`（彩色主版）。
3. **底色不可控**（照片、纹理、渐变、视频）：按 §5.4 的**照片底判据**测一次——亮度对比 **≥ 2.0 : 1** 且 ΔE00 **≥ 20** 可用彩色版；达不到就降为 `-mono-white`，或先在标志下方加一块 ≥60% 的纯色压底再上 `-on-dark`。
4. **单色场景**（单色印刷、打标、传真、盖章）：`-mono`；深色承印物用 `-mono-white`。
5. **不得**在低对比底上直接压彩色版——例如 `#7A8B87` 这类中灰底上，四色的对比度会落到 1.22–1.23 : 1（实测 `#7A8B87` 底）。
6. **不得**自行提亮/加深某一色去"改善"对比度；四色是一组，改动任一色即破坏 §1.3 的方位语义。

### 5.4 照片底判据（2026-11-07 实测补充）

为什么单独定一条：**WCAG 1.4.11 的 3 : 1 只适用于文字与 UI 控件，logotype 是明确豁免项。**
照片底上标志的识别靠"形 + 色差"，不靠单一亮度差，硬套 3 : 1 会把本来清楚的标志判死、也会放过
"ΔE 够但亮度塌在一起"的情况。故本部门内部下限取 **亮度对比 ≥ 2.0 : 1 且 ΔE00 ≥ 20**（两者同时满足）。

| 场景 | 底色实测 | 对比度 | ΔE00 | 判定 |
|---|---|---|---|---|
| 站点"关于"段图标（150px，压在云图/光伏板上） | `#373539` 邻域中位 | **2.75 : 1** | 31–35 | 过 → 用彩色版 |
| 站点 CTA 竖版（图标 130px，压在光伏板照片上） | `#3A3C39` 邻域中位 | **2.54 : 1** | 26–39 | 过 → 用 `-on-dark` |
| 反例：中灰 `#7A8B87` 平涂底 | — | 1.22–1.23 : 1 | 23–33 | **不过**（ΔE 够但亮度塌）→ 必须转白或换底 |

量法：在实拍/实渲染图里取标志外接框外 8–20px 的环带取中位色（避开高光），
用 `设计部/工具/contrast.py` 算对比与 ΔE00。**照片底必须在最终稿的实渲染图上量，不能拿设计稿猜。**

## 6. 错误用法（禁止清单）

| # | 错误 | 为什么不行 | 正确做法 |
|---|---|---|---|
| 1 | **拉伸/压扁**（宽高比 ≠ 4.113 或 1.410） | 卡尺量的几何，比例一错，"四向等权"的语义就塌了 | 等比缩放；需要不同比例时改版，不改文件 |
| 2 | **加描边/描边加粗/投影/发光** | 图形靠正负形关系成立，描边会把中心留白吃掉 | 保持平涂；需要压底时加底色块，不动标志 |
| 3 | **旋转/改尖角角度** | 60.8° 与四向 90° 是识别点；转 45° 会被读成"十字" | 永远正向使用（图标外接框与页面正交） |
| 4 | **低对比底上直接用彩色版** | 四色在中灰底上对比度跌到 1.22–1.23 : 1 | 改 `-mono-white` 或换底 |
| 5 | **在留白 x 内放文字/图形** | 标志被"粘"到别的内容上，识别度与专业感双降 | 至少留图标高 ÷ 4 |
| 6 | **单独改字标的字体、字重、字距、大小写** | 字标是转曲路径，与图形是同一套光学关系 | 用现成 SVG/PNG，不重排字 |
| 7 | **拆开单用某一块颜色 / 重排四色方位** | 四色对应四个业务方向（资本/货物/服务/信息） | 四色成套使用 |
| 8 | **16px 用标准形 / 20px 以下用图标** | 中心孔塌到 1px，四块糊成一团 | 16px 用 `icon-micro16`；图标不低于 16px |

## 7. 文件命名规则

```
astraroad-<form><variant>.<ext>
astraroad-<form><variant>-<px>.png          # PNG 一律带尺寸后缀
```

| 段 | 取值 |
|---|---|
| `<form>` | `icon` ｜ `icon-micro16` ｜ `horizontal` ｜ `vertical` |
| `<variant>` | 空（彩色主版）｜ `-on-dark`（反白）｜ `-mono`（单色黑）｜ `-mono-white`（单色白）；**单用图标时白色写成 `-white`**（图标没有「深底版」这一档，只有彩色/黑/白） |
| `<px>` | 16 / 32 / 48 / 64 / 128 / 256 / 512 / 1024（PNG 的**宽**，单位 px） |
| `<ext>` | `svg` ｜ `png` ｜ `ico` |

示例：`astraroad-horizontal-on-dark.svg`、`astraroad-vertical-mono-512.png`、`astraroad-icon-micro16-16.png`

固定入口文件（不改名）：`favicon.ico`（16 微缩 / 32 标准 / 48 标准三档内嵌）、
`apple-touch-icon-180.png`、`icon-192.png`、`icon-512.png`。

## 10. 复现与变更

```bash
# 1) 生成全部 SVG（需 /usr/bin/python3 + fontTools）
/usr/bin/python3 设计部/工具/build_astraroad_official.py svg
# 2) 栅格化 PNG（需 playwright；脚本见 设计部/工具/render_svg_batch.py）
~/.venvs/webscrape/bin/python3 设计部/工具/render_svg_batch.py <_build/manifest.json>
# 3) 打 favicon.ico + 写文件清单与哈希
/usr/bin/python3 设计部/工具/build_astraroad_official.py final
```

- 图形来源：`18-四向航道/icon.svg`、`icon-micro16.svg`（业主定稿，**只读**）。构建时脚本会用生成器
  复算四个路径并与锁定文件逐字比对，不一致直接报错（`geo.regen_match`）。
- 尺寸/间距参数集中在脚本顶部（`XR_H`、`GAP_H`、`VW_K`、`GAP_V`、`TRACK`），改其一即产生新版本，需另起编号。
- 每次改动后 `final` 会重写 `_build/file-manifest.json`（含 md5），用于比对"哪一版上线"。
